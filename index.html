Game Setup

Implemented rules notes
  • Roll 2 dice each turn to produce resources on matching number tiles (except where the Ghost sits).
  • Build ships to expand and hideouts to score points.
  • First player to 7 hideouts wins.
  • Gold can be used as a wildcard when paying costs.
  • Rolling 7 moves the Ghost to block one tile.
